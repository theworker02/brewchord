# brewchord

Brew structured JSON chord payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/brewchord/

## Install / run

```bash
git clone https://github.com/theworker02/brewchord.git
cd brewchord
node src/cli.js
node --test
```
